## 一次飞行

1. 在飞行查询页选择城市和范围。长沙可直接点击绿色适飞网格。填写时间、机型与高度，查询飞行条件。实时空域与审批通过 UOM 核对。
2. 查看「今日飞行窗口」，点击小时格可调整开始时间。「飞前准备」勾选项随计划保存。「分析航拍」保留路线指数、小时天气、备选时段和距航线 500 米内的沿途景点。
3. 保存计划后可生成报备说明。到「我的计划」打开「报备给场地方」，选择「本机演示」或「导出报备包」。文件由用户交给场地方。公告提醒仅在程序运行时检查。
4. 值班员可导入报备包，人工确认观察与报备的对应，记录回访并导出核对回执。公众可导入回执。飞完后可以从计划记录实际飞行，或在「飞行日志」手动新建。

## 运行和数据

在 Windows 打包目录双击 `Skyguard.exe`，保留同目录的运行文件。开发环境使用 Python 3.13 x64，从工程根目录运行以下命令。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
```

长沙适飞网格从湖南省发改委的原始数据生成。下载 [官方 ZIP](https://fgw.hunan.gov.cn/fgw/xxgk_70899/gzdtf/gzdt/202605/33975865/files/664bcd483b7d4a0783a4aebd81134cd5.zip)，保存为 `hunan-grid.zip`（放在仓库外），再从工程根目录执行以下命令。原始文件的 SHA-256 见 `skyguard/assets/hunan-airspace-202605.source.json`。

```powershell
.\.venv\Scripts\python.exe scripts/import_hunan_grid.py ..\hunan-grid.zip skyguard\assets\hunan-airspace-202605.npz
.\.venv\Scripts\python.exe run.py
```

如需进入低空治理演练，先在启动程序的 PowerShell 会话中设置 `$env:SKYGUARD_DUTY_PASSWORD` 为自选密码。这个入口面向本机演练。贡献流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。

业务数据保存在 `%LOCALAPPDATA%\SkyguardDesktop`。使用同一 Windows 用户和原数据目录可打开旧计划、观察、任务及审计。高德、AI 和和风天气继续使用本机加密设置。Open-Meteo 提供已有的高度层风速补充。长沙适飞网格显示 2026 年 5 月基础版次，其余四城显示边界接入状态。

## v0.10.0 航线与航拍机位

- **选点查飞** 保留圆形和多边形查询。在结果卡点「画航线」，把选点带到航线编辑器。
- **编辑航线** 按飞行顺序添加航点。拖动修改位置，右键或在表单内删除。可设起飞点、单侧宽度、总航速和逐点高度、悬停，支持撤销、重做和环绕、横移、拉升模板。黄段需核对或申请，红段有飞行限制。草稿可在「我的计划」载入。
- **帮我找机位** 选题材或输入「周末想拍湘江日落」，选具体机型后可查看天气参与计算的推荐指数。点「在地图上看」预演一条方案，点「做成计划」进入飞前准备与报备流程。
- **我的计划** 在阶段卡完成本机报备、开始和结束飞行及保存日志。从「查看报备」导出或查看已有报备。需要正式飞行审批时到 UOM 核对。
- **值班对应** 新报备用虚线画航线，事件详情显示横向、高度、时间偏离。缺高度时显示待核对。旧版范围报备在计划卡中只读，值班端沿用范围对应。

## v0.10.1 航拍助手工作区

打开飞行查询后，可直接在地图上画航线，也可输入拍摄偏好查看机位与时段。手绘航线有起点和终点后可查飞，点击航段中点的加号可以插入航点。预览候选时保留手绘航线，采用候选后可编辑起飞点与路线，再查飞和保存。高级设置包含航速、走廊宽度、坐标与镜头模板。

机位推荐显示分时天气和能见度。雷暴等异常时提示改期。地图目录中的起飞点有待现场确认时，先选起飞点。我的计划可复制航线、改期并重新查飞。结束飞行后，日志优先使用实际起止时间。

升级时删除本机旧版圆形、多边形计划及对应报备。已记录的飞行日志保留并解除旧计划关联。

## v0.12.0 模拟飞行与低空协同演练

公众端从「我的计划」打开飞行中的计划，选择「模拟飞行」。拖动地图控制方向，滚轮或 W / S 升降，空格暂停。「按航线飞」「触发返航」「模拟失联」可快速切换练习。飞行中可提交本机失联求助，查看提醒和回执。

值班端在「态势监控」选择「态势演练」。选取城市和托管方式，拖动时间轴回看。当前关注、处置按钮、行动记录和问答集中在右侧城市低空值班副手。

「设置 → 管理」可查看区域类型与预演排班。演练库和处置记录存于独立的 training.sqlite3。现场核验按已配置观察岗组织。人员行程显示步行估算。



## v0.13.0 飞行记录与值班核对

顶栏系统时间可切换真实时钟或演示时钟。第一次进入演示时间会复制本机业务数据库，之后演示数据保存在 data 目录下的 demo 子目录。可暂停、加速、向前跳转、保存或读取演示存档。

飞行查询支持查一个点及三步画航线。保存计划后在「我的计划」完成本机报备。到可起飞时段，点击「开始飞行」，即可使用鼠标记录航迹。值班端「态势监控」的报备飞行列表显示实时比对、提醒和操作记录。结束后可核对，回执与偏离摘要回到飞手计划。

## v0.16.0 城市低空智能值班助手

态势演练从长沙橘子洲、广州海心沙和上海徐汇滨江三个精选情景中选择。每场涵盖五架无人机，回放时长两分钟，支持 1×、2×、4× 和拖动进度。自动处置会模拟提醒、派员与安全备降引导。关键确认模式将派员和在途改派交给值班员。点击进度条刻度可跳到突发时刻，点击行动记录也可定位现场。

## v0.16.0 自由沙盘

在「低空治理」中打开「自由沙盘」。可在空白页载入本城示范考题，或自行设定城市、日期、时刻与天气。高德地标搜索和周边探测覆盖市中心 15 km 编排范围。重点管控现场、应急备降点、人员和航点均可在地图上放置和拖动。第 2 步可切换预设机群，并在航线上查看突发触发位置。

第 3 步可连续点放人员，选中人员查看当前天气下的有效核验覆盖范围，并保存最多三套方案。第 4 步以 2× 开播，可注入未报备飞行、阵风、低电和人员受阻。打开「复盘与策略对比」时，系统自动结算至少两套已保存的方案。预案保存在本机应用数据目录的 `sandboxes/` 下。

地图顶栏的「图例」随公众规划、城市推演和沙盘编辑切换。左下角「帮助」打开四页使用指南，包含真高、坐标、覆盖半径和治理评分口径。设置页可复制或打开本机数据目录。

界面精修通过 477 项 pytest 和四套地图 JavaScript 测试。开发态诊断、双主题桌面 QA、自由沙盘专项 QA 和打包诊断均通过。实机验收采用长沙和上海的高德在线底图，并覆盖 1440×900 与 1280×800。

本次模式切换改造通过 478 项 pytest 和四套地图 JavaScript 测试。开发态诊断、双主题桌面 QA 与打包版诊断均通过。实机截图记录长沙高德底图上的普通模式、密码弹窗和低空治理态势演练。
